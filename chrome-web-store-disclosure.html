Chrome Web Store Data Use

Post-Purchase Guardian · Last updated November 11, 2026

Single purpose

Track Amazon.com order items and return deadlines locally so users can manage returns and receive optional reminders.

Prominent disclosure

Post-Purchase Guardian reads supported Amazon.com order-page content only when you choose Scan Amazon. It stores order and product details, displayed or user-confirmed return deadlines, statuses, and reminder settings in Chrome local storage in your browser profile. It does not upload order records to the developer, use analytics or advertising trackers, or access Amazon cookies or credentials. If you choose Add to Google Calendar, the extension opens a prefilled Google Calendar link containing the product name, Amazon order date, return deadline, and Amazon order URL. Product images may be requested directly from Amazon's image servers when displayed. You can remove stored records with Clear all data in Settings.

Data handled and purpose

  • Amazon order-page content: order IDs, dates and links; product names, links, images, seller and quantity when shown; and explicit return-deadline text. Read only to scan the supported page and maintain the return list.
  • User-provided information: edited deadlines, product statuses, and reminder preferences. Used to manage local records and schedule reminders.
  • Reminder state: scheduled reminder date, delivery timestamp, and an idempotency key. Used to avoid duplicate notifications and restore reminder scheduling.

Collection, sharing, and retention

Records stay in Chrome local extension storage in the user's browser profile. There is no developer-operated account, cloud sync, analytics, advertising, data sale, or server upload. Records remain until the user clears extension data or removes the extension or browser profile.

When the user opens an order, the browser visits Amazon. Product images may be fetched from Amazon image servers. Only when the user requests a Calendar link, the prefilled link sends the product name, order date, return deadline, and Amazon order URL to Google Calendar. Chrome or the operating system may show product names and deadlines in notifications when enabled. The extension does not read Amazon cookies, passwords, or credentials, call Amazon order APIs, submit returns, or save calendar events.
